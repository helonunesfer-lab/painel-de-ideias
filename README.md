# painel-de-ideias

## Sobre o projeto

O Painel de Ideias é uma aplicação simples feita em React para adicionar, visualizar, concluir e remover ideias.

## Funcionalidades

- Adicionar uma nova ideia.
- Mostrar todas as ideias cadastradas.
- Marcar uma ideia como concluída.
- Remover uma ideia.
- Mostrar a quantidade de ideias e quantas foram concluídas.
- Mostrar uma mensagem de erro quando o campo estiver vazio.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS

## Como executar o projeto

Primeiro, instale as dependências:

npm install

Depois, execute o projeto:

npm run dev

Após isso, abra o endereço mostrado pelo terminal no navegador.

## Conceitos utilizados

O projeto utiliza:

- "useState" para controlar os dados.
- "map()" para mostrar e atualizar as ideias.
- "filter()" para remover e contar ideias concluídas.
- "spread (...)" para criar novas listas.
- Formulário controlado com "value" e "onChange".
- Validação do campo de texto.
- Renderização condicional.
